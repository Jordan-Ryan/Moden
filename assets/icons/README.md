# Icon SVGs

`components/TabIcon.tsx` loads these files with `react-native-svg`:

- `today.svg`
- `settings.svg`
- `sleep.svg`
- `food.svg`
- `heart-rate.svg`
- `hydration.svg`
- `mindfulness.svg`
- `activity.svg`

The same directory also contains `running.svg`, `cycling.svg`, `hiit.svg`, `walking.svg`, `strength.svg`, and `workout.svg`. `TabIcon` does not reference them. The activity icons used by `ActivityIcon` on Android and web are under `assets/icons/activity/`.
