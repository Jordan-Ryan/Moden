# Activity icon SVGs

`components/ActivityIcon.tsx` uses these files on Android and web. On iOS it renders `expo-symbols` instead.

Files in this directory, and the keys in `ACTIVITY_ICONS`:

- `running.svg`
- `cycling.svg`
- `hiit.svg`
- `walking.svg`
- `strength.svg`
- `rowing.svg`
- `football.svg`
- `workout.svg`

The component comment points at Icons8's iOS SF Regular set as the source style for these SVGs: https://icons8.com/icons/all--os-ios--style-sf-regular
